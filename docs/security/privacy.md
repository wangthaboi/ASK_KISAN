# Privacy boundary

## MVP — Proposed

Public chat may use voluntarily supplied crop, district, season, and language context for the current session. Do not treat this as a reason to create a farmer profile or persist it by default.

## Future — Proposed

Profiles, land history, government identifiers, benefit/application status, phone numbers, financial data, and account-linked documents require explicit consent, authorization, minimization, retention/deletion rules, and privacy-safe audit logging.

No confirmed private-data database tables or authenticated flows exist in the inspected repository.
