# Frontend user flows

The primary proposed flows are documented in [project user roles and primary journeys](../project/user-roles-and-primary-journeys.md).

The implemented MVP flow is: open the public query page → ask a question → receive a grounded answer or a calm error/empty-source state → ask another question using the same anonymous browser-session ID. The current backend does not persist or use conversation history, so follow-up context remains planned.
