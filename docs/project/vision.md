# Product vision

ASK_KISAN aims to be a reliable conversational assistant for Indian farmers, focused on public agricultural guidance and government-scheme information. The working prototype is part of Build What Moves India.

## Product principles

- Prefer verified, source-grounded information over broad unsupported answers.
- Make crop, district, season, and language context optional and useful.
- Do not require an account for public information.
- Clearly separate public guidance from individualized eligibility, financial, or private-record decisions.

## Status

- **Implemented:** a terminal proof-of-concept, derived-vector retrieval, a grounded public `/query` API, and a focused web UI with source identifiers.
- **Proposed:** visible human-readable source context and a conversational product with persisted follow-up context.
- **Not Yet Implemented:** mobile UI, account system, or administrator workflow.
