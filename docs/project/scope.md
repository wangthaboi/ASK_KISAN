# Product scope

## MVP scope — Proposed

Anonymous farmers can ask public questions about cultivation, pests, nutrients, irrigation, public advisories, and government schemes. They may supply crop, district, season, and language as session context. Answers should acknowledge uncertainty and use approved source material once retrieval exists.

## Out of MVP scope

Authenticated profiles, private farmer records, benefit/application status, identity verification, payment/bank details, and personalized recommendations are **Proposed future work**, not current functionality.

## Evidence

The current repository has a terminal OpenAI chat script and a small FastAPI service, but no farmer-facing frontend, chat endpoint, authentication, or retrieval implementation. See [user roles and journeys](user-roles-and-primary-journeys.md).
